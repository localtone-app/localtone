LocalTone Privacy Policy

Last updated: November 11, 2026

What the extension does

LocalTone is a Chrome side-panel extension that helps you write replies on social platforms (Threads, Reddit, X, Instagram, TikTok). When you click "Grab", it reads the text of the post or comment you select, and when you click "Generate" or "Translate", it sends that text to Google's Gemini API to produce reply suggestions and translations.

Data we handle

  • Text you select on a page (a post or comment), and the instructions you type in the panel.
  • Settings you enter: your Gemini API key, language preferences, profile description and promo information.

We do not collect browsing history, account credentials, cookies, or any data from pages you did not explicitly grab.

Where data goes

  • Stored locally: settings and the last grabbed post are stored only in your browser's local storage on your device. The developer has no server and cannot see them.
  • Sent to Google: when you request a reply or translation, the selected text, your instructions and the relevant settings are sent directly from your browser to the Google Gemini API (generativelanguage.googleapis.com) using your own API key. That processing is governed by Google's Gemini API Terms and Privacy Policy. Note that on Google's free tier, Google may use submitted content to improve its products.
  • No data is sold, shared with third parties, or used for advertising.

Your control

You can clear any field in the panel at any time. Uninstalling the extension deletes all locally stored data.

LocalTone 개인정보처리방침

최종 수정일: 2026년 11월 11일

확장 프로그램의 기능

LocalTone은 SNS(Threads, Reddit, X, Instagram, TikTok)에서 댓글 작성을 돕는 크롬 사이드패널 확장 프로그램입니다. 사용자가 [가져오기]를 누르면 선택한 게시글·댓글의 텍스트를 읽고, [생성]이나 [번역]을 누르면 그 텍스트를 Google Gemini API로 보내 댓글 추천과 번역을 받습니다.

처리하는 정보

  • 사용자가 페이지에서 직접 선택한 글(게시글·댓글)과 패널에 입력한 요청 내용
  • 사용자가 입력한 설정값: Gemini API 키, 언어 설정, 프로필 소개, 홍보 정보

방문 기록, 계정 정보, 쿠키, 사용자가 직접 가져오지 않은 페이지 내용은 수집하지 않습니다.

정보의 저장과 전송

  • 로컬 저장: 설정값과 마지막으로 가져온 원문은 사용자 기기의 브라우저 저장소에만 저장됩니다. 개발자는 별도 서버를 운영하지 않으며 이 정보에 접근할 수 없습니다.
  • Google 전송: 댓글 생성·번역을 요청하면 선택한 텍스트, 요청 내용, 관련 설정이 사용자 본인의 API 키로 브라우저에서 Google Gemini API로 직접 전송됩니다. 해당 처리는 Google의 Gemini API 약관과 개인정보처리방침을 따릅니다. Google 무료 등급에서는 전송된 내용이 Google 제품 개선에 사용될 수 있습니다.
  • 정보를 판매하거나 제3자에게 제공하거나 광고에 사용하지 않습니다.

사용자의 권리

패널의 모든 입력값은 언제든 지울 수 있으며, 확장 프로그램을 삭제하면 로컬에 저장된 모든 정보가 삭제됩니다.
